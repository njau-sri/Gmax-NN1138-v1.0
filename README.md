# Gmax-NN1138-v1.0

The data files can be downloaded from the [GitHub release assets](https://github.com/njau-sri/Gmax-NN1138-v1.0/releases).

`Gmax_NN1138_v1.0.genome.fasta.gz` is the genome sequence file of NN1138-2;

`Gmax_NN1138_v1.0.gene.gff3.gz` is the gene annotation file of NN1138-2;

`Gmax_NN1138_v1.0.cds.fa.gz` is the coding sequence (CDS) file of NN1138-2;

`Gmax_NN1138_v1.0.pep.fa.gz` is the protein sequence file of NN1138-2.

`soybean.505.NN.GASM.vcf.gz` and `soybean.505.NN.SNPLDB.vcf.gz` are the GASM and SNPLDB genotype files of the CHSSGP population using NN1138-2 as the reference genome, respectively;

`soybean.505.Wm82.GASM.vcf.gz` and `soybean.505.Wm82.SNPLDB.vcf.gz` are the GASM and SNPLDB genotype files of the CHSSGP population using Wm82 as the reference genome, respectively.
